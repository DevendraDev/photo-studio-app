# Subhash Photos

A responsive React storefront demo for a Maharashtrian photo lab and studio in
Kolhapur. It includes festive bookings, Karizma album finishes, personalized photo
gifts, and a camera-gear catalogue with filters and product comparison.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

Booking confirmations and the cart are local demos; no payment is processed.
Product prices are illustrative. Photography and fonts are
loaded from external image and font hosts, so an internet connection is needed
for those assets.
